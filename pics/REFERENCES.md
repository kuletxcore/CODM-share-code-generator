# Calibration screenshots

This folder held the in-game screenshots used to fit the preview to the game (see [docs/AFTER-MERGE.md](../docs/AFTER-MERGE.md), section 7). They were removed after calibration to keep the repo small. They are still in git history: check out commit `98f46df` to get them back.

| Set | Device and graphics | Scene |
| --- | --- | --- |
| `pics/` | Oppo F11, Low | Firing Range, Nuketown |
| `pics/Batch 2/` | Infinix GT50 Pro, Max | Practice Range |
| `pics/F11 Low/` | Oppo F11, Low, camera held still | Practice Range |
| `pics/F11 Low/Extras/` | Infinix GT50 Pro | Brightness 25 and Saturation 25, the curves below 50 |

Each shot changes one setting from the default, so the difference isolates that setting. Need more tests? Add a new set here with its device, graphics level and scene.
