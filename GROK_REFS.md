# IMFDB Call of Duty screencaps

Full-size in-game / multiplayer screencaps scraped from archived [IMFDB](https://www.imfdb.org/) pages (via the Wayback Machine). Real-world reference photos, logos, icons, and cover art were excluded.

## Folders

| Folder | Game | Images |
|--------|------|--------|
| `bo6_mp_screencaps/` | Call of Duty: Black Ops 6 | 625 |
| `mwiii_screencaps/` | Call of Duty: Modern Warfare III (2023) | 575 |

**Total:** 1,200 full-size images (mostly 1920×1080).

## Sources

- Black Ops 6 (archived 2026-11-20): https://web.archive.org/web/20261120151714/https://www.imfdb.org/wiki/Call_of_Duty:_Black_Ops_6
- Modern Warfare III (2023) (archived 2026-11-20): https://web.archive.org/web/20261120154040/https://www.imfdb.org/wiki/Call_of_Duty:_Modern_Warfare_III_(2023)

Images were downloaded from `imfdb.org/images/` (full-size originals, not 600px thumbnails).

This is an orphan branch of reference images only. It does not contain the share-code generator code from other branches.
